# แหล่งรวมงานวิจัยสำหรับนิสิตมหาวิทยาลัย

เว็บไซต์ Static HTML/CSS/JS สำหรับ GitHub Pages โดยใช้ Google Sheets เป็นแหล่งข้อมูลหลัก

## โครงสร้างข้อมูลที่เชื่อมกับ Google Sheets

เว็บไซต์อ่าน 3 Sheet ตามชื่อจริงในไฟล์ Google Sheets:

1. `รวบรวมวิจัย` — ข้อมูลหลักของงานวิจัย
   - วันที่นำเอกสารเข้า
   - ID งานวิจัย
   - ชื่องานวิจัย
   - ชื่อผู้แต่ง/คณะผู้แต่ง
   - ปีที่เผยแพร่
   - แหล่งที่มา/วารสาร (URL)
   - ลิงค์งานวิจัย

2. `ตรวจสอบความน่าเชื่อถือ` — ผลการตรวจสอบ
   - ID งานวิจัย
   - ชื่องานวิจัย
   - ผู้แต่ง/คณะผู้แต่งงานวิจัย
   - ลิงค์งานวิจัย
   - ผู้ตรวจ
   - เกณฑ์ประเมิน: การรับรอง
   - เกณฑ์การประเมิน: ระเบียบวิธีวิจัย/ระบุตัวอย่าง
   - ผลการตรวจสอบ
   - เกี่ยวข้องกับคณะ
   - เกี่ยวข้องกับสาขา
   - สถานะการตรวจสอบ (TRUE/FALSE)

3. `เสนอ` — งานวิจัยที่เสนอ
   - ID งานวิจัย
   - ชื่องานวิจัย
   - ผู้แต่ง/คณะผู้แต่งวิจัย
   - ลิงค์งานวิจัย
   - ลิงค์แหล่งที่มา
   - คณะที่เกี่ยวข้องกับงานวิจัย
   - สาขาที่เกี่ยวข้องกับงานวิจัย

## การเชื่อมข้อมูล

`ID งานวิจัย` เป็นคีย์หลักในการจับคู่ข้อมูลระหว่าง Sheet ทั้ง 3 ส่วน

- ข้อมูลหลักมาจาก `รวบรวมวิจัย`
- ข้อมูลการตรวจสอบมาจาก `ตรวจสอบความน่าเชื่อถือ`
- ข้อมูลงานเสนอ/คณะ/สาขาสำรองมาจาก `เสนอ`
- `ผลการตรวจสอบ` แสดงเป็นข้อความสรุปตามที่กรอกใน Sheet
- `สถานะการตรวจสอบ` ใช้ TRUE/FALSE ตาม Sheet โดยไม่เปลี่ยนความหมาย

## สำคัญ

เว็บไซต์ต้องสามารถอ่าน Google Sheets ได้จาก browser หาก Sheet ไม่เปิดให้อ่านแบบสาธารณะ เว็บไซต์จะใช้ข้อมูลสำรองใน `app.js` แทน

ไม่มีระบบสมาชิก / Login / Register
