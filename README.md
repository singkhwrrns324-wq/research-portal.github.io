# เว็บไซต์จริง: แหล่งรวมงานวิจัยสำหรับนิสิตมหาวิทยาลัย

โปรเจกต์นี้สร้างจากแนวทาง UI ของภาพ Reference ที่ผู้ใช้ให้มา 2 ภาพ:
1. หน้าแรก/หน้ารวมงานวิจัย
2. หน้าค้นหา + หน้ารายละเอียดงานวิจัยและการตรวจสอบความน่าเชื่อถือ

## วิธีเปิด
ดับเบิลคลิก `index.html` หรือเปิดผ่านเว็บเบราว์เซอร์

## ฟังก์ชันที่ใช้งานได้
- Navigation ระหว่างหน้า
- ค้นหาจากชื่อเรื่อง ผู้แต่ง คณะ สาขา และ Keyword
- Filter ปี / คณะ / สาขาวิชา
- Filter ตามหมวดหมู่
- เรียงงานวิจัย
- คลิกงานวิจัยเพื่อดูรายละเอียด
- แสดงข้อมูลผู้แต่ง บทคัดย่อ วัตถุประสงค์ วิธีวิจัย
- แสดงสถานะตรวจสอบและเปอร์เซ็นต์ความน่าเชื่อถือ
- Responsive Desktop / Tablet / Mobile
- ไม่มี Login / Register / ระบบสมาชิก

## สิ่งที่ยังเป็นข้อมูลตัวอย่าง
ข้อมูลใน `app.js` เป็น mock data เพื่อให้เว็บทดลองใช้งานได้ทันที หากต้องการใช้งานเป็นระบบจริงระดับ production สามารถเปลี่ยน DATA ใน app.js เป็นข้อมูลจากฐานข้อมูล/API ได้
